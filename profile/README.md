> One named BackyardEOS run. Finish the capture. Leave a note the next person can read.

## How BackyardEOS Sits

BackyardEOS does not replace the mount, the planetarium, or the Canon body you already own. It sits beside them as a named backyard desk for one job: which imaging session is live, which frames landed, and what the next person should read. A local BackyardEOS profile is enough for everyday work at the PC beside the mount.

If two people share that PC, each keeps a BackyardEOS style of their own. The live target list stays small on purpose. Extra objects wait for their own title instead of crowding the run.

A first visit should be one short capture, then the same BackyardEOS desk the next night. That is enough to see if the layout holds.

Canon stills belong with the settings that made them. Keep BackyardEOS camera settings next to BackyardEOS Canon capture.

Name the imaging session before the first light frame. An untitled dump is not a run.

Focus, ISO, and exposure live on the backyard desk, not only in the camera menu.

When clouds interrupt, leave the session title on BackyardEOS so the next run continues instead of starting empty.

## Traffic Light

| Signal | On the BackyardEOS board | What you do |
|--------|----------------------|-------------|
| Green | Named session, short live target list | Continue the same Canon capture |
| Amber | Two targets mixed in one run | Split the set before a long exposure |
| Red | No title, no note, frames unlabeled | Stop and name the session first |
| Clear | Handoff written, live targets few | Close BackyardEOS and leave the desk |
| Hold | Camera still cooling or settling | Wait before you start BackyardEOS Canon capture |
| Stale | A finished object still on the board | Drop it from the live imaging session |
| Split | Lights mixed with darks in one folder | Separate BackyardEOS backyard desk paths |
| Review | Settings on the body disagree with the desk | Recheck BackyardEOS camera settings |
| Pause | Clouds over the target | Park the run without closing the session title |

## Open Order

1. Open the last BackyardEOS imaging session, not a new empty backyard desk.
2. Read the frame list and the last handoff.
3. Finish one visible capture inside BackyardEOS.
4. Write what changed, then close with fewer loose frames than you found.
5. If the set feels crowded, drop anything that belongs to a different BackyardEOS job.
6. Confirm the Canon body on USB is the camera you own beside the mount.
7. Match BackyardEOS camera settings to the filter and exposure plan.
8. Keep BackyardEOS Canon capture in a named folder per target.
9. Store darks and flats off the live light-frame list.
10. Leave the session title on the desk before you pack the mount.
11. Note focus and temperature in the handoff while they still match the frames.
12. Copy a preview JPEG beside the raw stills for the next person.
13. If clouds stopped the run, write the last good subframe number.
14. Recheck USB before the next BackyardEOS Canon capture starts.

## After a Week

A week in BackyardEOS is not a bigger frame dump. It is the same title, a shorter live target list, and a note that still makes sense on the next clear night. If every object is pinned, nothing stands out. Take finished targets off the live set so the next visit starts on the run that is still open.

Other programs stay where they are. BackyardEOS only keeps the path back: session name, Canon capture, camera settings, handoff.

Leave BackyardEOS with a quieter backyard desk than the one you opened. The next visit should start on that session, not in an untitled stills folder.

Lights, darks, and settings belong together. If one drifted, fix BackyardEOS camera settings before the next subframe.

A named imaging session is the difference between a run and a pile. Keep the title when you pack the mount.

If USB dropped overnight, reopen the same BackyardEOS imaging session. Do not start a second untitled capture.

## Field Note

BackyardEOS is easier to trust when the backyard desk stays smaller than the stills folder it came from. Name the session, keep the live target, finish one visible capture, and write what changed. Extra objects wait for their own title.

The same loop fits a home pad, a travel mount, or a shared observatory PC. Open the last BackyardEOS imaging session and continue. Do not rebuild the layout from scratch.

A Canon capture is a map of frames on the PC beside the mount. Leave BackyardEOS pointed at that map, with settings a second person can read.

If the sky closes, park the title. The next clear night should open the same BackyardEOS backyard desk.
